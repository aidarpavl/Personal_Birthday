# Туған күндер

- **Сайт (Streamlit):** за день до дня рождения показывает напоминание, в сам день показывает статус поздравлений.
- **Рассылка (GitHub Actions):** каждый день в 09:17 по Казахстану поздравляет сегодняшних именинников. В 13:17 повторяет только то, что не ушло. Сайт для этого открывать не нужно.

Текст: `ФИО сізді туған күніңізбен құттықтаймыз!!!`

Столбцы таблицы по порядку: A №, B ФИО, C дата `ДД.ММ.ГГГГ`, D телефон, E логин Instagram, F логин Telegram. Год рождения при сравнении не учитывается.

## Настройка

### 1. Таблица
«Настройки доступа» → «Все, у кого есть ссылка» → **Читатель**. Сейчас по ссылке её может менять любой, а рассылка доверяет этим данным.

### 2. GitHub
Создайте **приватный** репозиторий и загрузите проект:

```bash
git init -b main
git add .
git commit -m "Первая версия"
git remote add origin https://github.com/ЛОГИН/birthday-bot.git
git push -u origin main
```

Секреты добавляются в Settings → Secrets and variables → Actions:

| Секрет | Для чего | Где взять |
|---|---|---|
| `SHEET_ID` | таблица, обязательно | часть ссылки между `/d/` и `/edit` |
| `SHEET_GID` | лист, если не первый | значение `gid=` в ссылке |
| `MOBIZON_API_KEY` | SMS | кабинет mobizon.kz → API |
| `MOBIZON_SENDER` | имя отправителя, если зарегистрировано | кабинет Mobizon |
| `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` | Telegram | my.telegram.org → API development tools |
| `TELEGRAM_SESSION` | Telegram | `python tools/telegram_login.py` |
| `INSTAGRAM_SESSION` | Instagram | `python tools/instagram_login.py` |

Канал без секретов просто не запускается, поэтому можно подключать их по одному.

Скрипты входа запускаются на своём компьютере: `pip install -r requirements-sender.txt`. Их результат даёт полный доступ к аккаунту: храните его только в секретах GitHub.

### 3. Сайт
На share.streamlit.io создайте приложение: репозиторий, ветка `main`, файл `app.py`. В Advanced settings → Secrets вставьте:

```toml
APP_PASSWORD = "придумайте-пароль"
SHEET_ID = "id-вашей-таблицы"
```

Для кнопки «Отправить в Telegram» добавьте туда же `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION`. Для сайта лучше создать отдельную сессию, ещё раз запустив `tools/telegram_login.py`: одна сессия, используемая одновременно с разных серверов, может быть сброшена Telegram. Без этих секретов на сайте остаётся кнопка «Открыть чат в Telegram с готовым текстом»: ключи ей не нужны, но «Отправить» нажимаете вы сами.

### 4. Проверка
Actions → «Поздравления» → Run workflow. Галочка «Пробный запуск» стоит по умолчанию: ничего не отправится, в логе будет видно, кого поздравили бы. Без галочки сообщения уйдут по-настоящему.

## Как работают каналы

**SMS.** Через Mobizon, платно. В сообщении кириллицей 70 символов на один SMS, поэтому длинные ФИО занимают 2 SMS.

**Telegram.** Боты не могут писать первыми и не находят людей по телефону, поэтому письмо уходит от вашего личного аккаунта. Сначала используется логин из столбца F, а если его нет или он не найден, телефон. Найденный по телефону номер добавляется в ваши контакты. Если человека не удалось найти, в журнале будет `not_found`.

**Instagram.** Официальный API не даёт написать первым: человек должен сам написать аккаунту за последние 24 часа. Автоотправка здесь идёт через неофициальную библиотеку `instagrapi`. Это нарушает правила Instagram: аккаунт могут временно ограничить или заблокировать, вход с серверов GitHub может требовать подтверждения, а библиотека может перестать работать после изменений Instagram. Если вы не задаёте `INSTAGRAM_SESSION`, автоотправка выключена, а на сайте есть кнопка, открывающая чат, и готовый текст.

## Защита
- Журнал `sent_log.csv` хранит только № из таблицы, канал и статус, без имён и телефонов.
- Одно и то же сообщение не уйдёт дважды. Если сервис не ответил вовремя, статус будет `uncertain`, и повтора не будет: проверьте вручную.
- Если именинников в один день больше 10, рассылка отменяется. Лимит меняется через переменную окружения `MAX_RECIPIENTS_PER_DAY`.
- Если отправка не удалась, запуск в Actions станет красным, и GitHub пришлёт письмо.
